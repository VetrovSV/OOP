# Путеводитель по основам Java для студентов, знакомых с C и Python

## 1. Введение в Java
- История языка, платформа JVM, отличия от C и Python
- Система типов и принципы автоматического управления памятью (garbage collection)

## 2. Примитивные типы данных и переменные
- Примитивные типы: `byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean`
- Объектные типы‑обёртки и автоупаковка/распаковка
- Ключевое слово `var` (вывод типа из Java 10)
- Константы `final`

## 3. Управляющие конструкции
- Условные операторы `if`, `else`, тернарный оператор
- Оператор `switch` (включая расширения с `String` и «arrow» синтаксис)
- Циклы `for`, `while`, `do‑while`
- Расширенный `for‑each` для массивов и коллекций

## 4. Массивы и строки
- Одномерные и многомерные массивы, инициализация и копирование
- Класс `String`: неизменяемость, основные методы
- `StringBuilder` / `StringBuffer` для изменяемых строк

## 5. Функции (статические методы)
- Объявление и вызов методов, передача параметров по значению
- Перегрузка методов, переменные‑аргументы (`varargs`)
- Псевдоним `static import` для упрощения вызова

## 6. Ввод‑вывод
- Стандартный ввод/вывод: `System.out`, `System.err`, `Scanner`
- Работа с файловой системой: `java.io.File`, `FileReader`, `FileWriter`
- Кратко о `java.nio.file` (Paths, Files) для современных задач

## 7. Обработка исключений
- Иерархия исключений, проверяемые vs непроверяемые
- Блоки `try‑catch‑finally`
- Пользовательские исключения (наследование от `Exception`)

## 8. Коллекции и обобщения (Generics)
- Интерфейсы `Collection`, `List`, `Set`
- Реализации `ArrayList`, `LinkedList`, `HashSet`,
- Основы обобщений: параметризированные типы, ограничение `<T extends …>`


## 10. Пакетирование и модульность
- Организация кода в пакеты, директива `package`
- Импорт классов: `import` и `import static`
- Кратко о системе модулей Java 9 (module-info.java) – что будет изучено дальше

## 11. Инструменты разработки и сборки
- Компиляция и запуск: `javac`, `java`
- IDE: IntelliJ IDEA / Eclipse / VS Code (основные настройки)
- Обзор систем сборки: Maven, Gradle (как создать простой проект)
