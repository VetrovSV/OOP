# Основы Java

Модуль предназначен для студентов, знакомых с языком C и Pascal\Python.

# Результаты освоения модуля

- **Знание платформы Java**: понимание роли JVM, различий между JRE и JDK, принципов работы байт‑кода и кроссплатформенных возможностей.
- **Уверенное владение типовой системой**: умение выбирать и использовать все примитивные типы, их обёртки, автоупаковку, `var` и константы `final`.
- **Навыки работы с управляющими конструкциями**: построение корректных условных операторов, `switch` (включая arrow‑syntax), различных видов циклов, меток и управления потоками выполнения.
- **Операции с массивами и строками**: создание, инициализация, копирование массивов, работа с `String`, `StringBuilder`/`StringBuffer`, а также применение методов форматирования.
- **Проектирование и применение методов**: объявление сигнатур, перегрузка, использование `varargs`, `static import`, а также применение принципа единственной ответственности.
- **Работа с вводом‑выводом**: использование консольного ввода/вывода, файлового API (`java.io`), буферизованных потоков и современного NIO (`Path`, `Files`).
- **Обработка исключений**: построение надёжного кода через `try‑with‑resources`, различение проверяемых и непроверяемых исключений, создание пользовательских исключений.
- **Использование коллекций и generics**: выбор подходящих реализаций (`ArrayList`, `HashSet`, `HashMap` и др.), работа с итераторами, сортировка, а также построение типобезопасных обобщённых классов и методов.
- **Организация кода в пакеты и модули**: построение логической структуры проекта, применение `package`, `import`, а также базовое понимание модульной системы Java 9.
- **Навыки работы с инструментами разработки**: компиляция, запуск, использование IDE (IntelliJ IDEA, Eclipse, VS Code), базовый опыт работы с системами сборки Maven и Gradle, написание юнит‑тестов с JUnit 5 и применение статических анализаторов кода.

Эти результаты соответствуют требованиям современных учебных программ по программированию и позволяют студенту уверенно переходить к более продвинутым темам, включая объектно‑ориентированное программирование, многопоточность и архитектурные паттерны.

## 7. Обработка исключений
- Иерархия `Throwable` → `Error` vs `Exception`
- Проверяемые (`checked`) исключения (`IOException`, `SQLException`), непроверяемые (`unchecked`) (`NullPointerException`, `IllegalArgumentException`)
- Блоки `try`, `catch`, `finally`
- Множественные `catch`, `catch (IOException | SQLException e)`
- Перехват и повторный бросок (`throw e`), вложенные исключения (`throw new MyException("msg", e)`) 
- Пользовательские исключения: наследование от `Exception` (checked) или `RuntimeException` (unchecked)
- Ресурсный менеджер `try‑with‑resources` (автоматическое закрытие `AutoCloseable`)
- Принципы: не скрывать исключения, логировать, использовать информативные сообщения
- **Пример:** "Обработчик файлов с try‑with‑resources"
- **Пример:** "Пользовательское CheckedException для валидации"
- **Ресурсы:** глава «Exceptions» в книге "Effective Java", курс Coursera "Fundamentals of Java Programming" (секция «Exception Handling»)
