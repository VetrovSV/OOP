## 2. Классы и объекты в Java
- Объявление класса. Поля и методы. Ключевое слово `this`.
- Области видимости: `private`, по умолчанию (package-private), `protected`, `public`.
- Инкапсуляция и сокрытие данных. Принцип «чёрного ящика».
- Геттеры и сеттеры. Проверка предусловий в сеттерах.
- Контроль постоянства: `final` поля и методы.
- Конструкторы: по умолчанию, с параметрами, перегрузка. Цепочка `this(...)`.
- Инициализация полей: значения по умолчанию, инициализаторы, статические блоки.
- **Пример:** [класс `Seconds`](../examples/java/simple-class) с инкапсуляцией и проверкой предусловий.

## 5. Наследование
- Базовые и производные классы. Ключевое слово `extends`.

- Переопределение методов (`@Override`). Перегрузка и переопределение.
- Области видимости и наследование. `protected`.
- Преобразование типов: восходящее и нисходящее. `instanceof`, [сопоставление с образцом](../examples/java/pattern_matching.md).
- Почему в Java нет множественного наследования классов. Роль интерфейсов.

# Отличия от ООП в C++

Некоторые темы из курса ООП на C++ в Java отсутствуют или решаются иначе. Их полезно упомянуть при сравнении языков.

- Перегрузки операторов нет (кроме `+` для строк).
- Деструкторов нет: память освобождает сборщик мусора. Для освобождения ресурсов используются `try-with-resources` и интерфейс `AutoCloseable`.
- Правила пяти нет: копирование объектов выполняется явно, оператор присваивания не перегружается.
- Множественного наследования классов нет, вместо него — интерфейсы.
- Указателей нет, есть ссылки. Указатели на функции заменяют функциональные интерфейсы и ссылки на методы.
- Выравнивание памяти и POD — детали реализации JVM, в прикладном коде не рассматриваются.
