# Статические члены класса

В главе про классы и объекты мы разбирали поля и методы, принадлежащие объекту: у каждого объекта свои значения полей, методы работают с полями своего объекта. Но бывают члены, общие для всех объектов класса, — статические. Они принадлежат классу в целом, а не отдельному объекту.


## 1. Статические поля

Статическое поле (static field) — одно на весь класс, а не на каждый объект. Оно существует, даже если объектов класса не создано. Обращаются к нему через имя класса:

```java
class Counter {
    static int total;    // общее число созданных объектов
}
```

Классическое применение — счётчик экземпляров: поле увеличивается в конструкторе, и по нему видно, сколько объектов класса создано:

```java
class Seconds {
    private static int instances;   // сколько объектов создано

    Seconds() {
        instances++;
    }

    static int getInstances() {
        return instances;
    }
}
```

В C++ статические поля объявляются так же, но определяются отдельно от класса. В Python аналог — атрибуты класса.


## 2. Статические методы

Статический метод (static method) вызывается через имя класса, без объекта:

```java
double d = Math.sqrt(2.0);
```

Статический метод не имеет доступа к полям экземпляра: у него нет объекта, а значит, нет и `this`. Он может обращаться только к статическим членам класса и своим параметрам.

В C++ статические методы устроены так же. В Python — методы, помеченные `@staticmethod`.


## 3. Статические константы

Пара `static final` — константа класса: одно значение на весь класс, изменить его нельзя. Имена констант принято писать заглавными буквами:

```java
class Physics {
    static final double G = 9.81;    // ускорение свободного падения
}
```

Примеры из стандартной библиотеки: `Math.PI`, `Integer.MAX_VALUE`.


## 4. Утилитарные классы

Класс, в котором собраны только статические методы, называют утилитарным (utility class). Примеры — `Math`, `Collections`. Объекты такого класса не нужны, поэтому конструктор делают приватным — создать экземпляр извне нельзя:

```java
class StringUtils {
    private StringUtils() {
        // запрещаем создание объектов
    }

    static boolean isPalindrome(String s) {
        // ...
    }
}
```

Приватный конструктор — единственный способ запретить создание объектов класса.


## 5. Порядок инициализации класса

Статические поля инициализируются один раз, при первой загрузке класса, — до создания первого объекта. Кроме инициализаторов, есть статический блок — код, выполняемый при загрузке класса:

```java
class Config {
    static Map<String, String> settings;

    static {
        settings = new HashMap<>();
        settings.put("theme", "dark");
    }
}
```

Статические инициализаторы и блоки выполняются в порядке объявления. В C++ статические поля инициализируются до `main`; в Java — при первой загрузке класса, то есть при первом обращении к нему.


## Практические советы

- Делайте член статическим, если его значение или поведение не зависит от конкретного объекта.
- Из статического метода нельзя обратиться к полю экземпляра — не пытайтесь использовать `this`.
- Константы объявляйте как `static final`, имена пишите заглавными буквами.
- Утилитарным классам — приватный конструктор.
