# 7. Файловый ввод-вывод

> **План раздела.** Материал рассчитан на студентов, знакомых с консольным вводом-выводом, циклами и строками. Изложение идёт от простых текстовых файлов к основным средствам Java для работы с файлами.

## Цели раздела

После изучения раздела студент должен уметь:

- записывать текст и числа в файл и читать их обратно;
- обрабатывать файл целиком, не зная заранее количества строк или чисел;
- читать строки и записи, состоящие из нескольких полей;
- выбирать подходящий API: `Scanner`, `Reader`/`Writer`, байтовые потоки или `Path`/`Files`;
- закрывать файловые ресурсы и понимать, почему при чтении и записи возможны ошибки.

## 1. Зачем программе файлы

- Чем файл отличается от консоли: данные сохраняются после завершения программы и могут быть переданы другой программе.
- Короткое сравнение с C (`FILE*`, `fopen`, `fscanf`, `fprintf`) и Python (`open`, `read`, `write`, контекстный менеджер `with`).
- Текстовый и двоичный файлы: человекочитаемое представление, размер и совместимость.
- В этом разделе сначала используются текстовые файлы: числа в них записаны как символы, например `42` или `3.14`.

## 2. Записываем числа в текстовый файл

- Минимальный пример записи нескольких значений разных типов: `int`, `long`, `float`, `double`.
- Форматирование чисел при записи: `PrintWriter` и `printf`; разделители — пробелы, табуляция или перевод строки.
- Объяснить, что форматирование `%.2f` округляет отображаемое значение, но не меняет саму переменную.
- Выбор кодировки для текстовых данных, особенно если файл содержит кириллицу; в примерах использовать UTF-8.
- Важное различие: запись может создать новый файл или перезаписать существующий; добавление в конец — отдельный режим.
- **Пример:** программа записывает числа в файл `numbers.txt`, затем показывает ожидаемое содержимое файла.

## 3. Читаем данные из созданного файла

- Открываем `numbers.txt` и читаем значения в том же порядке и форматах, в каком они были записаны.
- Пример с `Scanner`: `nextInt()`, `nextLong()`, `nextFloat()`, `nextDouble()`.
- Требование к данным: содержимое файла должно соответствовать ожидаемому формату; при несовпадении возможны ошибки разбора.
- Пояснить, что `Scanner` разделяет данные на токены по пробельным символам, а `nextLine()` читает всю оставшуюся строку.
- Отдельно предупредить о локали: десятичный разделитель в числах должен совпадать с настройкой `Scanner` или быть задан явно.
- **Пример:** прочитать и вывести на экран значения, записанные в предыдущем подразделе.

## 4. Читаем числовой файл до конца

- Файл содержит последовательность чисел, а их количество заранее неизвестно.
- Цикл чтения до конца файла с `Scanner.hasNextInt()` или `hasNextDouble()` и соответствующим `next...()`.
- Обсудить, что делать, если встретился некорректный токен, а не конец файла: сообщить об ошибке и не зацикливаться на нём.
- Различить «прочитать до конца» и «сначала загрузить всё содержимое в память».
- **Пример:** прочитать числа из `values.txt`, посчитать их количество и сумму.

## 5. Читаем строки до конца файла

- Чтение построчно с `BufferedReader.readLine()`; конец файла обозначается результатом `null`.
- Сохранение пробелов внутри строки и отличие чтения строки от чтения токена через `Scanner.next()`.
- Использование `Files.readAllLines` только для небольших файлов, когда допустимо загрузить все строки в память.
- **Пример:** вывести все строки файла и посчитать число строк.

## 6. Читаем несколько записей с полями разных типов

- Формат файла: одна запись на строку, поля разделены точкой с запятой: `целое;вещественное;текст`.
- Пример содержимого `records.txt`:

  ```text
  101;12.5;Книга по Java
  102;7.25;Практикум по C
  ```

- Читать файл построчно, каждую строку разделить на поля, преобразовать первое поле через `Integer.parseInt`, второе — через `Double.parseDouble`, третье оставить строкой.
- Проверить количество полей и обработать некорректную строку с понятным сообщением.
- Объяснить выбор разделителя и ограничение простого формата: если данные могут содержать разделитель или кавычки, нужен полноценный формат, например CSV-библиотека.
- **Пример:** прочитать все записи до конца файла и вывести поля в удобном виде.
- **Связанный пример:** записать такие же записи в файл, затем прочитать их обратно.

## 7. Пути и сведения о файлах

- Путь к файлу — не то же самое, что содержимое файла; относительный и абсолютный пути.
- Класс `File` как знакомое представление пути и файла; базовые проверки существования и доступности.
- Современный API `Path` и `Files`: `Path.of`, `Files.exists`, `Files.size`.
- Операции с файлами и каталогами: создание каталогов, копирование и удаление (`Files.createDirectories`, `Files.copy`, `Files.delete`).
- Объяснить, что рабочий каталог программы влияет на смысл относительного пути.

## 8. Символьные и байтовые потоки

- Символьные потоки `Reader`/`Writer` для текста; байтовые потоки `InputStream`/`OutputStream` для произвольных байтов.
- Краткий обзор `FileReader`/`FileWriter`, `FileInputStream`/`FileOutputStream`.
- Буферизация: `BufferedReader`/`BufferedWriter` уменьшает число обращений к файлу; `PrintWriter` удобен для форматированного текстового вывода.
- Явно указать, что числа в текстовом файле — текстовые символы, а не двоичное представление примитивов.
- Не углубляться в сериализацию объектов: это отдельная тема.

## 9. Закрытие ресурсов и обработка ошибок

- Файлы могут отсутствовать, быть недоступны или завершиться ошибкой во время чтения/записи; основные примеры ошибок — `IOException`.
- Ресурсы нужно закрывать; в примерах использовать `try-with-resources`.
- Кратко показать, что `try-with-resources` закрывает поток автоматически, а подробный разбор исключений оставить разделу [«Обработка исключений»](15_exceptions.md).
- Не перехватывать исключение пустым `catch` и не скрывать сообщение об ошибке.

## 10. Современный API `Path` и `Files`

- Чтение и запись небольших текстовых файлов через `Files.readString`, `Files.writeString`, `Files.readAllLines`, `Files.write`.
- Чтение и запись больших файлов потоково через `Files.newBufferedReader` и `Files.newBufferedWriter`.
- Указывать UTF-8 там, где важно предсказуемое чтение и запись текста.
- Сравнить краткие операции `Files` с явной работой через потоки: простота против контроля над обработкой данных.

## Практические советы и типичные ошибки

- Согласовывать формат записи и формат чтения; не менять порядок полей незаметно.
- Использовать один и тот же разделитель и явно договориться о кодировке.
- Для больших файлов читать данные построчно, а не целиком в память.
- Не путать путь к файлу с его содержимым и проверять, откуда отсчитывается относительный путь.
- Закрывать потоки с помощью `try-with-resources`.
- Не использовать байтовые потоки для текста без понимания кодировки.
