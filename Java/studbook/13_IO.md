# Консольный ввод-вывод в Java


## 1. Стандартный ввод/вывод

### `System.out.println`

Метод `System.out.println` используется для вывода текста на консоль. Он автоматически добавляет символ новой строки в конец выводимого текста.

Пример:
```java
System.out.println("Hello, World!");
```
выведет на консоль:
```
Hello, World!
```

### `System.err`

`System.err` используется для вывода сообщений об ошибках. Это полезно для отделения обычных сообщений от сообщений об ошибках.

Пример:
```java
System.err.println("Error: File not found");
```
выведет сообщение об ошибке в консоль:
```
Error: File not found
```

Обычно в консоли обычные сообщения и сообщения об ошибках никак не отличаются визуально, но при запуске программы всегда можно определить куда именно будут выводится сообщения об ошибках: в консоль, файл или не будут выводится вовсе. 


### `Scanner`

Документация: https://docs.oracle.com/en/java/javase/20/docs/api/java.base/java/util/Scanner.html

Если для вывода используется просто функция (статический метод), то для чтения используется специальная переменная типа `Scanner`.
Класс `Scanner` используется для чтения данных из консоли. Он предоставляет методы для чтения различных типов данных, таких как строки, числа и т.д.

**Пример.** Программа запрашивает у пользователя его имя и выводит приветственное сообщение.
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Enter your name: ");
        
        String name = scanner.nextLine();
        System.out.println("Hello, " + name + "!");
    }
}
```

- `System.In: InputStream` -- переменная для работы со стандартным потоком ввода (ввод с консоли).
- `System.out: PrintStream` -- переменная для работы со стандартным потоком вывода (вывод в консоль).
- `System.err: PrintStream` -- переменная для работы со стандартным потоком ошибок (вывод ошибок в консоль).

**Пример ввода данных:**
```
Enter your name: Anna
Hello, Anna!
```

### Использование `scanner.nextLine()`

Метод `scanner.nextLine()` используется как для чтения строки, так и для очистки буфера. Когда вы читаете данные разных типов (например, сначала число, затем строку), символ новой строки, оставшийся в буфере после чтения числа, может быть прочитан как пустая строка. Чтобы избежать этого, используйте `scanner.nextLine()` для очистки буфера.

### Другие важные методы `Scanner`

Класс `Scanner` предоставляет различные методы для чтения данных из консоли. Вот некоторые из наиболее часто используемых методов:

- `nextByte() -> byte` -- чтение значения типа byte.
- `nextShort() -> short` -- чтение значения типа short.
- `nextInt() -> int` -- чтение значения типа int.
- `nextLong() -> long` -- чтение значения типа long.
- `nextFloat() -> float` -- чтение значения типа float.
- `nextDouble() -> double` -- чтение значения типа double.
- `nextBoolean() -> boolean` -- чтение значения типа boolean.
- `next() -> String` -- чтение одного слова (до пробела).
- `nextLine() -> String` -- чтение всей строки (до символа новой строки).

**Пример использования различных методов `Scanner`:**
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Enter your age: ");
        int age = scanner.nextInt();
        scanner.nextLine(); // Очистка буфера
        
        System.out.print("Enter your name: ");
        String name = scanner.nextLine();
        
        System.out.print("Enter your height (in meters): ");
        double height = scanner.nextDouble();
        scanner.nextLine(); // Очистка буфера
        
        System.out.print("Are you a student? (true/false): ");
        boolean isStudent = scanner.nextBoolean();
        scanner.nextLine(); // Очистка буфера
        
        System.out.printf("Name: %s, Age: %d, Height: %.2f, Student: %b", name, age, height, isStudent);
    }
}
```

**Пример ввода данных:**
```
Enter your age: 25
Enter your name: John
Enter your height (in meters): 1.75
Are you a student? (true/false): false
Name: John, Age: 25, Height: 1.75, Student: false
```



## 2. Форматированный вывод

### `System.out.printf`

Метод `System.out.printf` используется для форматированного вывода. Он позволяет указывать формат вывода с использованием спецификаторов формата, аналогично функции `printf` в языке C.

Пример:
```java
int age = 25;
String name = "John";
System.out.printf("Name: %s, Age: %d", name, age);
```

Этот код выведет на консоль:
```
Name: John, Age: 25
```

### `format`

Метод `String.format` используется для создания форматированных строк. Он возвращает отформатированную строку, которую можно затем вывести на консоль или использовать в других целях.

Пример:
```java
int age = 25;
String name = "John";
String formattedString = String.format("Name: %s, Age: %d", name, age);
System.out.println(formattedString);
```

Этот код создаст отформатированную строку и выведет ее на консоль:
```
Name: John, Age: 25
```

### Лучшие практики

1. **Использование `Scanner`**. Всегда закрывайте объект `Scanner` после использования, чтобы избежать утечек ресурсов. Однако, если вы используете `Scanner` для чтения из `System.in`, закрытие `Scanner` также закроет `System.in`, что может привести к проблемам, если вы попытаетесь снова прочитать из консоли.

2. **Очистка буфера**. При чтении данных разных типов (например, сначала число, затем строку) используйте `scanner.nextLine()` для очистки буфера после чтения числа.

3. **Форматированный вывод**. Используйте `System.out.printf` для вывода данных в определенном формате, это делает вывод более читаемым и понятным.

### Частые ошибки

1. **Исключение `InputMismatchException`**. Это исключение возникает, когда тип данных, введенных пользователем, не соответствует ожидаемому типу. Например, если пользователь вводит строку вместо числа.

2. **Пропуск строки**. При чтении строки после числа, символ новой строки, оставшийся в буфере после чтения числа, может быть прочитан как пустая строка. Чтобы избежать этого, используйте `scanner.nextLine()` для очистки буфера.


## Заключение

Консольный ввод-вывод является важной частью любого приложения на Java. Понимание того, как работать с консолью, позволяет разработчикам создавать интерактивные программы, которые могут взаимодействовать с пользователем. Использование `System.out.println`, `System.err`, `Scanner` и форматированного вывода помогает сделать программы более удобными и понятными для пользователя.
