# Массивы в Java

Массивы в Java — это контейнеры, которые хранят фиксированное количество элементов одного типа. Длина массива задается при его создании и не может быть изменена впоследствии.

> Массивы в Java похожи на массивы в C, но имеют некоторые отличия, например, они являются объектами, а не просто блоками памяти, и поддерживают встроенные методы для работы с ними.

> **Важно:** раз `массив` — объект, он создаётся через `new` и хранится в **куче** (heap). Подробнее — в разделе [«Управление памятью и оператор new»](20_memory.md).

---

## Объявление массива

Массив объявляется с указанием типа данных и квадратных скобок `[]`. Например:

```java
int[] anArray; // Объявление массива целых чисел
```

Можно также разместить квадратные скобки после имени переменной, но это считается менее предпочтительным стилем:

```java
int anArray[]; // Допустимо, но не рекомендуется
```

---

## Создание и инициализация массива

Массив создается с помощью оператора `new` (оператор динамического выделения памяти), после чего указывается тип данных и размер массива:

```java
int[] anArray = new int[10]; // Создание массива из 10 целых чисел
```

После создания массива можно инициализировать его элементы:

```java
anArray[0] = 100; // Инициализация первого элемента
anArray[1] = 200; // Инициализация второго элемента
```

Также можно создать и инициализировать массив в одной строке с помощью синтаксиса инициализации:

```java
int[] anArray = {100, 200, 300, 400, 500, 600, 700, 800, 900, 1000};
```

---

## Доступ к элементам массива

Элементы массива доступны по индексу, который начинается с `0`. Например:

```java
System.out.println("Элемент с индексом 0: " + anArray[0]); // Выведет 100
```

Попытка доступа к элементу за пределами массива вызовет ошибку (исключение) `ArrayIndexOutOfBoundsException`.

---

## Многомерные массивы

Java поддерживает многомерные массивы, которые представляют собой массивы массивов. Например:

```java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
```

Доступ к элементам многомерного массива -- через оператор квадратные скобки, отдельные для каждого индекса. Например, для двумерных массивов (матриц), сначала будет записан индекс стоки, а потом столбца. 

```java
System.out.println("Элемент на позиции [1][2]: " + matrix[1][2]); // Выведет 6
```

---

## Копирование массивов

Для копирования массивов можно использовать метод `System.arraycopy()`:

```java
int[] source = {1, 2, 3, 4, 5};
int[] destination = new int[5];
System.arraycopy(source, 0, destination, 0, source.length);
```

Также можно использовать метод `Arrays.copyOfRange()` из класса `java.util.Arrays`:

```java
import java.util.Arrays;

int[] source = {1, 2, 3, 4, 5};
int[] destination = Arrays.copyOfRange(source, 0, source.length);
```

---

## Полезные методы для работы с массивами

Класс `java.util.Arrays` предоставляет множество полезных методов для работы с массивами:

- `Arrays.sort()` — сортировка массива.
- `Arrays.binarySearch()` — бинарный поиск элемента в отсортированном массиве.
- `Arrays.equals()` — сравнение двух массивов на равенство.
- `Arrays.fill()` — заполнение массива указанным значением.
- `Arrays.toString()` — преобразование массива в строку для удобного вывода.

Пример использования:

```java
import java.util.Arrays;

int[] numbers = {5, 2, 8, 1, 3};
Arrays.sort(numbers); // Сортировка массива
System.out.println(Arrays.toString(numbers)); // Выведет [1, 2, 3, 5, 8]
```

## Длина массива

Длина массива хранится в свойстве `length`. Например:

```java
System.out.println("Длина массива: " + anArray.length); // Выведет 10
```

---

## Пример: Работа с массивом

```java
public class ArrayExample {
    public static void main(String[] args) {
        // Создание и инициализация массива
        int[] numbers = {10, 20, 30, 40, 50};
        
        // Вывод элементов массива
        for (int i = 0; i < numbers.length; i++) {
            System.out.println("Элемент с индексом " + i + ": " + numbers[i]);
        }
        
        // Изменение элемента массива
        numbers[2] = 300;
        
        // Вывод измененного массива
        System.out.println("Измененный массив: " + Arrays.toString(numbers));
    }
}
```

Вывод программы:

```
Элемент с индексом 0: 10
Элемент с индексом 1: 20
Элемент с индексом 2: 30
Элемент с индексом 3: 40
Элемент с индексом 4: 50
Измененный массив: [10, 20, 300, 40, 50]
```

# Передача массивов в функции

Массивы в функции всегда передаются по ссылке.

Пример
```java
/// Заполняем массив значением x
static void fill_array(int[] arr, int x){
    for (int i = 0; i<arr.length; i++){
        arr[i] = x;
    }

    // при изменении формального параметр arr (элементов массива, а не ссылки arr) изменится и соответствующий фактический параметр 
}


public static void main(){
    int[] A = new int[1024];

    fill_array(A, 1729);
}
```

# Краткий обзор коллекций Java

Массивы в Java хороши, но у них есть фундаментальное ограничение: **фиксированный размер**. В C вы можете обойти это через `realloc`; в Python списки (`list`) динамически расширяются сами. Java предоставляет целый фреймворк коллекций (`java.util.Collection`), который покрывает практически любую потребность в хранении и обработке групп объектов.

> **Для студентов, знающих Python:** коллекции Java — это примерно то же, что встроенные типы `list`, `set`, `dict`, но с одним отличием -- тип элементов задаётся заранее.

---

## 1. Основные интерфейсы Collections Framework

Все коллекции Java организованы в иерархию интерфейсов. Вот три самых важных:

| Интерфейс | Описание | Аналог в Python | Аналог в C |
|-----------|----------|-----------------|------------|
| `List<E>` | Упорядоченная последовательность, доступ по индексу, дубликаты разрешены | `list` | Массив |
| `Set<E>` | Множество уникальных элементов, порядок не гарантирован | `set` | — |
| `Map<K,V>` | Словарь: ключ → значение | `dict` | — |

`<E>`, `<K, V>` — это **параметры типа** (generics). Они указывают, с каким типом работает коллекция. Подробнее generics будут разобраны позже, а пока воспринимайте это как «коллекция, настроенная на конкретный тип».

---

## 2. ArrayList — динамический массив

`ArrayList<E>` — это **аналог классического массива**, но с автоматическим управлением размером. Внутри он хранит обычный массив, а когда тот заполняется — создаёт новый большего размера и копирует элементы.


### Создание и базовые операции

```java
import java.util.ArrayList;

ArrayList<String> list = new ArrayList<>(); // Пустой список строк

list.add("Java");     // Добавление в конец — O(1) амортизированно
list.add("Python");
list.add("C");

String lang = list.get(0); // Доступ по индексу — O(1)
list.set(1, "C++");        // Замена элемента по индексу
list.remove(2);            // Удаление по индексу — O(n), так как элементы сдвигаются

int size = list.size();    // Текущее количество элементов (не путать с length!)
```

### Когда использовать ArrayList, а когда — обычный массив?

| Ситуация | Что выбрать |
|----------|-------------|
| Размер известен заранее и не меняется | Обычный массив (`int[]`)
| Элементы добавляются/удаляются в процессе | `ArrayList`
| Критична производительность и кэш-локальность | Обычный массив
| Нужны методы вроде `sort`, `binarySearch` | Любой: у массивов есть `Arrays.sort`, у списков — `Collections.sort`
| Нужно передать коллекцию в API, который требует `List` | `ArrayList` (он реализует `List`)

> **Практический совет:** в современном Java-коде `ArrayList` используется значительно чаще, чем обычные массивы. Если вы не уверены — берите `ArrayList`. Перейти с `ArrayList` на массив легко; наоборот — труднее.

### Итерация по ArrayList

```java
// Цикл for-each (работает с любой коллекцией)
for (String s : list) {
    System.out.println(s);
}

// Цикл по индексу (как с массивом)
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}
```

### Преобразование между массивом и ArrayList

```java
import java.util.Arrays;
import java.util.ArrayList;
import java.util.List;

// Массив → список
String[] arr = {"a", "b", "c"};
List<String> listFromArr = Arrays.asList(arr); // Но размер фиксирован!

// Чтобы получить полноценный ArrayList:
ArrayList<String> fullList = new ArrayList<>(Arrays.asList(arr));

// Список → массив
String[] backToArr = fullList.toArray(new String[0]);
```

## 3. Другие часто используемые коллекции

Кроме `ArrayList`, в стандартной библиотеке есть ещё несколько реализаций, которые вы будете встречать постоянно:

| Класс | Интерфейс | Особенность | Когда использовать |
|-------|-----------|-------------|-------------------|
| `LinkedList<E>` | `List`, `Deque` | Двусвязный список. Вставка/удаление в середине — O(1) (если уже есть ссылка на узел), но доступ по индексу — O(n) | Когда часто вставляете/удаляете в начале или середине списка |
| `HashSet<E>` | `Set` | Хеш-таблица. `add`, `remove`, `contains` — O(1) в среднем | Когда нужны только уникальные элементы и порядок не важен |
| `HashMap<K,V>` | `Map` | Хеш-таблица. `put`, `get`, `containsKey` — O(1) в среднем | Когда нужно отображать ключи на значения (словарь) |

Пример с `HashMap`:

```java
import java.util.HashMap;
import java.util.Map;

Map<String, Integer> grades = new HashMap<>();
grades.put("Alice", 90);
grades.put("Bob", 85);

int aliceGrade = grades.get("Alice"); // 90

for (Map.Entry<String, Integer> entry : grades.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}
```

> **Важно:** `ArrayList`, `LinkedList`, `HashSet`, `HashMap` — это **классы**. `List`, `Set`, `Map` — это **интерфейсы**. В коде принято объявлять переменную как интерфейс, а конкретный класс подставлять при создании: `List<String> list = new ArrayList<>();`. Это даёт гибкость — вы сможете заменить реализацию, не меняя остальной код.

---

## Практические советы

- ✅ Используйте `ArrayList` как основной контейнер для последовательностей элементов.
- ✅ Используйте `HashMap`, когда нужен быстрый поиск по ключу.
- ✅ Используйте `HashSet`, когда важна уникальность элементов.
- ❌ Не используйте `LinkedList`, если вам нужен только доступ по индексу — `ArrayList` сделает это быстрее.
- ❌ Не путайте `length` (поле массива) и `size()` (метод коллекции).
