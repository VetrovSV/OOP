# Строки в Java

Строки — одна из самых часто используемых структур данных в любой программе. В C строка — это массив `char` с ручным управлением памятью; в Python — встроенный тип `str` с богатым набором методов (функций). Java занимает промежуточную позицию. Строки здесь — не простые массивы из символов, а полноценные объекты (переменные) класса (типа) `String` с большим набором методов.
Как и в Python, они **неизменяемы** (immutable).

> `String` находится в пакете `java.lang`, который подключается автоматически — `import` для него не нужен.

---

## 1. Создание строк

Строковый литерал — это текст в двойных кавычках:

```java
String greeting = "Hello, world!";
```

Строку можно создать и другими способами:

```java
String s1 = "Java";                // литерал
String s2 = new String("Java");    // явное создание объекта
String s3 = String.valueOf(42);    // из числа: "42"
String s4 = "a" + "b" + "c";       // конкатенация: "abc"
```

### char и String — это разные вещи

`char` — примитивный тип, один символ в одинарных кавычках. `String` — объект, последовательность символов:

```java
char c = 'A';   // примитив
String s = "A"; // строка из одного символа
```

В отличие от C, где `char` — это байт (8 бит), в Java `char` — 16-битный код UTF-16. Это позволяет хранить символы любых языков:

```java
char cyrillic = 'я';

// символы можно задавать через их код или напрямую
char heart = '\u2764'; // символ ❤
char c1 = '\u262E'; // символ ☮
char c2 = '☮';

char pi_char = '\u03c0';    // символ π
char pi_char = '\u3c0';     // ошибка! задавать код нужно строго 4 цифрами

// Задавать также можно просто числом, удобнее всего в шестнадцатеричной записи 
// начальные нули не нужны, но нужен префикс 0x чтобы обозначить систему счисления с основанием 16 
char pi_char = 0x3c0;     
char pi_char = 960;     // десятичная система счисления тоже подойдёт, но чаще всего в таблицах символов приводятся именно шестнадцатеричные коды     


```

## 2. Неизменяемость (Иммутабельность)

Ключевое свойство `String` — **неизменяемость** (immutability). Ни один метод не меняет существующую строку: все методы, которые «что-то делают» со строкой, возвращают **новую** строку.

```java
String s = "Hello";
String upper = s.toUpperCase(); // НЕ меняет s, а возвращает новую строку
System.out.println(s);          // Hello — исходная строка не тронута
System.out.println(upper);      // HELLO
```

| Язык | Поведение строк |
|------|-----------------|
| C | `char[]` — изменяемый, памятью управляете вы |
| Python | `str` — неизменяемый, как в Java |
| Java | `String` — неизменяемый. Для изменяемых строк есть `StringBuilder` (см. раздел 6) |

### Что происходит при конкатенации

```java
String a = "Java";
String b = a + " 21"; // создаётся НОВАЯ строка, a не меняется
```

Оператор `+` со строками создаёт новый объект. В цикле из тысяч итераций это дорого — поэтому для построения строк используют `StringBuilder`.

### Пул строк и интернирование

JVM хранит строковые литералы в специальном **пуле строк** (string pool). Если два литерала совпадают, они могут ссылаться на один и тот же объект:

```java
String x = "abc";
String y = "abc";
System.out.println(x == y); // true — оба указывают на один объект из пула
```

Но это работает только для литералов. Строки, созданные через `new` или в результате вычислений, в пул не попадают:

```java
String z = new String("abc");
System.out.println(x == z); // false — это разные объекты!
```

> **Важно:** полагаться на интернирование в коде нельзя. Сравнивать строки нужно только через `.equals()` (см. раздел 4).

## 3. Основные методы String

| Метод | Что делает | Пример |
|-------|-----------|--------|
| `length()` | Длина строки | `"Java".length()` → 4 |
| `charAt(i)` | Символ на позиции i | `"Java".charAt(1)` → `'a'` |
| `substring(begin, end)` | Подстрока с begin по end-1 | `"Hello".substring(1, 3)` → `"el"` |
| `indexOf(s)` | Позиция первого вхождения (или -1) | `"Hello".indexOf("l")` → 2 |
| `contains(s)` | Содержит ли подстроку | `"Hello".contains("ell")` → true |
| `startsWith(s)` / `endsWith(s)` | Начинается/заканчивается ли | `"Hello".startsWith("He")` → true |
| `toLowerCase()` / `toUpperCase()` | Изменить регистр | `"Java".toUpperCase()` → `"JAVA"` |
| `trim()` | Удалить пробелы по краям | `"  x  ".trim()` → `"x"` |
| `replace(a, b)` | Заменить все вхождения | `"a-b-a".replace("a", "x")` → `"x-b-x"` |
| `split(regex)` | Разбить на массив по разделителю | `"a,b,c".split(",")` → `{"a","b","c"}` |

Пример:

```java
String path = "user/documents/report.txt";

int lastSlash = path.lastIndexOf('/');
String fileName = path.substring(lastSlash + 1); // "report.txt"

String[] parts = path.split("/");
System.out.println(parts[0]); // user

if (fileName.endsWith(".txt")) {
    System.out.println("Это текстовый файл");
}
```

> В отличие от Python, где `s[i:j]` — это срез, в Java используется метод `substring(begin, end)`, и конец — **исключён**: `"Hello".substring(1, 3)` даёт `"el"`, а не `"ell"`.

## 4. Сравнение строк: == vs equals

Это классическая ловушка для новичков. `==` сравнивает **ссылки** (указывают ли переменные на один объект), а `.equals()` — **содержимое**:

```java
String a = "abc";
String b = new String("abc");

System.out.println(a == b);      // false — разные объекты
System.out.println(a.equals(b)); // true — одинаковое содержимое
```

| Язык | Как сравнивают строки |
|------|----------------------|
| C | `strcmp(a, b)` — посимвольно |
| Python | `a == b` — по содержимому |
| Java | `a.equals(b)` — по содержимому; `a == b` — по ссылке |

**Правило:** строки сравниваем только через `.equals()`.

## 5. Преобразования: строка ↔ число

```java
// Число → строка
String s = String.valueOf(42); // "42"
String t = 3.14 + "";          // "3.14" (конкатенация с пустой строкой)

// Строка → число
int n = Integer.parseInt("42");        // 42
double d = Double.parseDouble("3.14"); // 3.14
```

Если строка не является числом, `parseInt` бросит исключение `NumberFormatException` — как `int()` в Python, который бросает `ValueError`. Обработка исключений — в разделе [«Исключения»](15_exceptions.md).

## 6. StringBuilder: изменяемые строки

`StringBuilder` — изменяемый «строитель» строк. Он нужен, когда строка собирается постепенно, например в цикле:

```java
// Плохо: каждая итерация создаёт новую строку — O(n²)
String result = "";
for (int i = 0; i < 1000; i++) {
    result += i + " ";
}

// Хорошо: StringBuilder меняет свой внутренний буфер — O(n)
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i).append(' ');
}
String result = sb.toString();
```

Основные методы:

| Метод | Что делает |
|-------|-----------|
| `append(x)` | Добавить в конец (число, строку, символ) |
| `insert(i, x)` | Вставить на позицию i |
| `delete(i, j)` | Удалить с i по j-1 |
| `reverse()` | Развернуть |
| `toString()` | Получить итоговую строку |

Пример — построение запроса:

```java
// Строим SQL-запрос из списка имён
String[] names = {"Alice", "Bob", "Carol"};

StringBuilder query = new StringBuilder("SELECT * FROM users WHERE name IN (");
for (int i = 0; i < names.length; i++) {
    if (i > 0) query.append(", ");
    query.append('\'').append(names[i]).append('\'');
}
query.append(')');

System.out.println(query);
// SELECT * FROM users WHERE name IN ('Alice', 'Bob', 'Carol')
```

> `StringBuilder` — аналог изменяемого списка символов. В Python для этого используют `list` + `''.join(...)`, в C — `realloc` и ручное копирование.

## 7. Форматирование: String.format и printf

`String.format()` работает как `printf` в C и f-строки в Python:

```java
String s = String.format("Привет, %s! Тебе %d лет.", "Иван", 20);
System.out.println(s); // Привет, Иван! Тебе 20 лет.
```

Основные спецификаторы:

| Спецификатор | Тип | Пример |
|--------------|-----|--------|
| `%s` | строка | `%s` → `"Java"` |
| `%d` | целое | `%d` → `42` |
| `%f` | дробное | `%.2f` → `3.14` |
| `%c` | символ | `%c` → `'A'` |

То же самое можно выводить сразу в консоль через `System.out.printf()` — см. раздел [«Консольный ввод-вывод»](13_IO.md).

## Практические советы

- ✅ Сравнивайте строки через `.equals()`, никогда через `==`.
- ✅ Стройте длинные строки через `StringBuilder`, а не через `+` в цикле.
- ✅ Используйте `String.format` для читаемого форматирования.
- ❌ Не пытайтесь «изменить» строку — методы возвращают новую, сохраняйте результат.
- ❌ Не путайте `char` (примитив, одинарные кавычки) и `String` (объект, двойные кавычки).
